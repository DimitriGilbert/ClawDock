# UI Shell Review (Gemini)

## Summary
The UI Shell has a good structural foundation using TanStack Router and Shadcn UI. The layout is correct. However, the dashboard is currently using **mock data** and lacks real-time connectivity to the backend stack events.

## Findings

### 1. Layout (`apps/web/src/routes/__root.tsx`)
- **Status**: **Pass**
- **Details**:
  - Correctly implements Sidebar and Header.
  - Responsive grid layout.
  - Displays Agent identity ("Clawthis").

### 2. Dashboard (`apps/web/src/routes/index.tsx`)
- **Status**: **Partial / Mocked**
- **Details**:
  - **Critical**: Relies on `MOCK_CONTAINERS` instead of calling `trpc.stack.listContainers`.
  - **Missing**: Real-time subscriptions (`trpc.stack.onContainerChange`).
  - **Missing**: Resource usage (CPU/Memory) in service cards.
  - **Visuals**: Uses proper Shadcn components (Badge, Card).

### 3. Navigation
- **Status**: **Pass**
- **Details**: Sidebar links to Stack, Chat, and Agent files correctly.

## Recommendations
1. **Wire up Data**: Replace `MOCK_CONTAINERS` with `trpc.stack.listContainers.useQuery()`.
2. **Add Subscriptions**: Implement `trpc.stack.onContainerChange.useSubscription()` to update the list in real-time.
3. **Resource Metrics**: Add CPU/Memory display to `ContainerRow` (backend support needed in `ContainerInfo` type if not already there).
